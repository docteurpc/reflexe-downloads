# Journal des modifications REFLEXE

Les changements sont regroupés par version publiée.

## [1.0.0] — 5 novembre 2026

Première version officielle de REFLEXE pour Windows.

Fonctionnalités annoncées dans la release :
- Diagnostic informatique local et présentation des principales informations de l'ordinateur.
- REFLEXE CLEAN : évaluation de la santé informatique du PC avec un score sur 100.
- Rapport de santé avec appréciation générale et recommandations.
- Application de bureau Windows installable.

Téléchargement et notes de version : [REFLEXE 1.0.0](https://github.com/docteurpc/reflexe-downloads/releases/tag/v1.0.0).
