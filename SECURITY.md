# Signalement d'un problème de sécurité

La sécurité des utilisateurs de REFLEXE est importante.

## Signaler une vulnérabilité

Si vous pensez avoir découvert une vulnérabilité dans l'application ou dans son processus de distribution, contactez :

**docteurpc.contact33@gmail.com**

Merci de fournir, dans la mesure du possible :
- une description claire du problème ;
- les versions de REFLEXE et de Windows concernées ;
- les étapes nécessaires pour reproduire le comportement ;
- un impact potentiel et, si utile, des captures d'écran expurgées de toute donnée personnelle.

## Divulgation responsable

Merci de ne pas publier de détails exploitables ni de données concernant d'autres utilisateurs avant d'avoir contacté l'éditeur et de lui avoir laissé la possibilité d'examiner le signalement.

N'incluez jamais de mots de passe, de clés privées, de jetons d'accès, de codes bancaires ou de données personnelles de tiers dans un signalement.

Ce dépôt ne propose pas de programme de récompense financière (bug bounty) annoncé. L'envoi d'un signalement ne vaut pas promesse de rémunération.
